# Manhwa Tracker

Application web de suivi de lecture de manhwa et manhua (catalogue Asura Scans et Vortex Scans).

- Catalogue avec couvertures, statut et nombre de chapitres
- Suivi personnel : chapitre en cours, note, statut de lecture
- Ajout de nouvelles séries à partir d'un lien
- Installable sur iPhone : ouvre le site dans Safari, puis Partager → « Sur l'écran d'accueil »

Les données de suivi restent sur l'appareil (localStorage). Utilise « Exporter mon suivi » en bas de page pour faire une sauvegarde.
